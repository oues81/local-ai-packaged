Use this entrypoint when the project declares external runtimes in `.ssot/agents/runtimes.json`. Git is the single source of truth; the runtime is derived from it. This entrypoint compares three commit hashes — the remote tracking branch, the local workspace HEAD, and the runtime-deployed commit — and reports one of four drift statuses.

**Default mode (report only, no runtime mutation):**

Run `npx --no-install acos-runtime-sync --root .` to produce a fresh `ACOS_RUNTIME_SYNC_REPORT.json`. This executes the declared `driftCheckCommand` and reads local git state. It does **not** execute the `syncCommand`.

**Sync mode (mutating, requires explicit request):**

Only run `npx --no-install acos-runtime-sync --root . --sync` when the user explicitly asks to push local changes to the runtime. The command first computes the drift report, then executes the declared `syncCommand` for each runtime that is not `runtime-diverged` (unless `--force` is also supplied). Never run sync automatically from `0020-resume`, `0640-doctor`, or any other entrypoint.

**Drift statuses:**

- `aligned` — remote, local, and runtime are on the same commit.
- `local-ahead` — local workspace HEAD is ahead of the remote tracking branch; the runtime matches the remote.
- `runtime-stale` — the runtime is behind the remote tracking branch.
- `runtime-diverged` — the runtime contains a commit not present in git (local or remote). Stop and ask the user to reconcile before continuing.

**Runtime-diverged stop condition:**

If the latest report shows `runtime-diverged`, do not continue with any work that mutates the runtime or canonical ACOS files unless the user has supplied an explicit `--force` flag to `acos-runtime-sync`. Surface the diverged state in `0020-resume` and `0640-doctor` and recommend manual reconciliation.

Do not edit `ACOS_RUNTIME_SYNC_REPORT.json` directly; it is generated by `acos-runtime-sync`.
