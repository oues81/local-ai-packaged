Create or update `specs/<feature-id>/plan.md` from the current specification and repository evidence.

1. Determine the feature ID from the user's request or the active spec.
2. Read `specs/<feature-id>/spec.md` and the plan template at `.ssot/agents/specs/plan-template.md`.
3. Order work by dependencies and risk. For every step identify affected surfaces, verification, rollback or compatibility concerns, and completion evidence.
4. Separate required work from optional improvements. Reference the data model and checklist when they already exist.
5. If the plan involves parallelizable work, document the parallelization strategy (wave type, lane grouping, max lanes, lane assignment) so `acos-wave-plan` can mechanically generate a wave-config.
6. Do not implement unless the user also authorized implementation.
