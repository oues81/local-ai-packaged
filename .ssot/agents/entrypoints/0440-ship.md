Prepare the active feature for delivery.

1. Determine the feature ID from the user's request or the active spec.
2. Confirm verification evidence, review the final diff, and update durable documentation and changelog where required.
3. Run `delivery.converge` (or read the existing `convergence.md`) to produce a gap analysis and delivery-readiness checklist.
4. Produce a concise delivery summary. Do not commit, push, publish, deploy, merge, or message external systems unless the user explicitly authorized that action.
